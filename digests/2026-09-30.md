## 🛠️ Release Notes
### Apigee API hub
- **[Feature]**: AI performance and Tool performance dashboards in API insights API insights in API hub now includes two dashboards for AI and agent traffic: AI performance reports token usage and model latency for the large language models called through your gateways, with filters for model and provider. Tool performance reports traffic, throughput, payload sizes, and latency for your Model Context Protocol (MCP) tools, with filters for MCP server, deployment, and tool name. For more information, see API insights dashboards . [Doc](https://docs.cloud.google.com/apigee/docs/apihub/api-insights-dashboard)

### Datastream
- **[Feature]**: Datastream now supports partial backfill for SQL Server,
Spanner, Oracle, PostgreSQL, and MySQL sources. Partial backfill lets
you load a specific subset of data from the source into the destination by
providing a SQL WHERE clause as a custom filter. For more information, see Initiate partial
backfill . [Doc](https://docs.cloud.google.com/datastream/docs/manage-backfill-for-the-objects-of-a-stream#initiatepartialbackfill)
