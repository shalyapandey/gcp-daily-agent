### Gemini Enterprise Agent Platform
- **[Feature]**: Govern agents on any CNCF-conformant Kubernetes cluster with Agent Gateway for cross-cloud (Limited Preview) Agent Gateway for cross-cloud is available in Limited Preview . It
extends
Agent Platform governance to agents that run on Cloud Native Computing
Foundation (CNCF)-conformant Kubernetes clusters outside of Google Cloud, such
as Amazon Elastic Kubernetes Service (Amazon EKS), Azure Kubernetes Service
(AKS), Red Hat OpenShift, and bare-metal clusters. Your
agents keep running where they are, but you govern them from one place: give
each agent a verifiable identity, register agents and MCP servers in Agent
Registry, and route their LLM, MCP, and A2A traffic through local Agent Gateway
proxies by using your existing service mesh or network stack. Those proxies
enforce access and Model Armor safety policies, and send access logs and agent
traces to Cloud Logging and Cloud Trace. Agent Gateway for cross-cloud is available at no charge during Limited Preview.
Other products that you configure with it, such as Model Armor, Cloud Logging, and
Cloud Trace, are billed at their standard rates. To request access, complete the access request form . For more information, see Set up Agent Gateway for cross-cloud .
