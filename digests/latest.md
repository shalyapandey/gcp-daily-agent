### Bigtable
- **[Feature]**: You can configure Bigtable tables with microsecond timestamp granularity to
capture and store high-frequency data. By supporting microsecond precision for
cell timestamps, Bigtable helps you prevent data loss from write collisions in
workloads with high event rates. This feature is generally available (GA) for instances in the Enterprise Plus edition. For more information, see Data type enforcement in Bigtable .
